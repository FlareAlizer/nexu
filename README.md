# NEXU — платформа онлайн-школы (MVP)

Платформа для олимпиадной онлайн-школы: курсы из уроков с видео, заданиями и тестами, проверка работ преподавателем, опыт и ранги для учеников, админка, уведомления в Telegram. Делал по техническому заданию заказчика, работа шла этапами M1–M6.

## Стек (решено)

Backend: Node.js + Express + TypeScript + Prisma + PostgreSQL 16. Frontend: React 18 + Vite + React Router + TanStack Query + Tailwind. Видео: Kinescope. Файлы: S3 (Selectel/Yandex). Уведомления и вход: Telegram (@nexuu_school_bot). Чат потока — в Telegram (решение от 12.07, вместо WebSocket из п.5.1). Прод: VPS (Spaceweb) + Docker Compose + Caddy (авто-HTTPS), CI/CD — GitHub Actions (`.github/workflows/deploy.yml`), бэкапы — `scripts/backup.sh`.

## Запуск dev

```bash
docker compose -f docker-compose.dev.yml up -d   # Postgres 16 на :5432
cd backend && cp .env.example .env && npm i && npx prisma migrate deploy && npm run seed && npm run dev  # :8000
cd frontend && npm i && npm run dev              # :5173, /api → :8000
```

Начальная миграция уже в репо (`backend/prisma/migrations/0_init`). Тесты: `cd backend && npm test`.
`npm run seed` создаёт демо-курс, поток и аккаунты `admin@ | teacher@ | student1@nexu.local`
(пароль — `SEED_PASSWORD`, по умолчанию `demo-nexu-2026`; на проде seed запрещён).

Telegram-вход локально не работает (виджету нужен HTTPS-домен, привязанный к боту через
/setdomain) — до покупки домена проверяем резервным email-входом.

## Заглушки внешних API

Ни один внешний сервис ещё не оплачен, поэтому платформа умеет работать без них.
Переключение автоматическое — по наличию ключей в `.env`, кода менять не нужно.

| Сервис | Без ключей (сейчас) | С ключами (прод) |
|---|---|---|
| S3 (файлы заданий) | файлы в `backend/.storage`, ссылка `/api/files/<токен>` с HMAC-подписью и TTL 10 мин | закрытый бакет, presigned URL 10 мин |
| Telegram (уведомления) | текст сообщения пишется в лог API, сценарий не рвётся | Bot API `sendMessage` |
| Kinescope (видео) | блок VIDEO с id `demo-*` → плеер-заглушка с таймлайном: можно прогнать правило «видео ≥80%» | iframe player API с трекингом |
| Sentry | выключен (нет `SENTRY_DSN` / `VITE_SENTRY_DSN`) | ошибки бэка и фронта; PII не шлём |

Контракт у заглушек тот же, что у боевых драйверов (`backend/src/services/storage.ts`,
`telegram.ts`), поэтому подключение реальных ключей — это только заполнение `.env`.

## Нагрузочное тестирование

```bash
cd backend && SEED_STUDENTS=500 npm run seed
RATE_LIMIT_PER_MIN=100000 LOGIN_RATE_LIMIT_PER_MIN=100000 npm start
cd .. && VUS=500 DURATION_S=60 node scripts/load-test.mjs
```

Скрипт без зависимостей: логинит 500 виртуальных учеников, гоняет сценарий
кабинет → курс → урок → прогресс видео, печатает p50/p95/p99 по эндпоинтам и проверяет
пороги (p95 ≤300 мс из п.4.1, ошибок ≤1%). Лимиты запросов поднимаются на время теста,
потому что 500 пользователей идут с одного IP. Запускать на стенде уровня прод-VPS.
